PYTHON COLLECTION DATATYPES
---------------------------

1. LIST
-----------------------------------------

Definition:
A list is an ordered and changeable collection of items.

Example:

fruits = ["apple", "banana", "mango"]

print(fruits)

Output:
['apple', 'banana', 'mango']

Accessing an item:

print(fruits[1])

Output:
banana

Changing an item:

fruits[1] = "orange"
print(fruits)

Output:
['apple', 'orange', 'mango']

Characteristics:
1. Ordered
2. Changeable (Mutable)
3. Allows duplicate values
4. Supports indexing
5. Supports slicing

Real-life Example:
Shopping cart items.


2. TUPLE
-----------------------------------------

Definition:
A tuple is an ordered and unchangeable collection of items.

Example:

colors = ("red", "green", "blue")

print(colors)

Output:
('red', 'green', 'blue')

Accessing an item:

print(colors[0])

Output:
red

Trying to change a value:

colors[0] = "yellow"

Output:
Error (Tuples cannot be modified)

Characteristics:
1. Ordered
2. Unchangeable (Immutable)
3. Allows duplicate values
4. Supports indexing
5. Supports slicing

Real-life Example:
Date of Birth (should not change).

3. SET
-----------------------------------------

Definition:
A set is an unordered collection of unique items.

Example:

numbers = {1, 2, 3, 2, 1}

print(numbers)

Output:
{1, 2, 3}

Duplicates are removed automatically.

Adding an item:

numbers.add(4)

print(numbers)

Output:
{1, 2, 3, 4}

Characteristics:
1. Unordered
2. Changeable
3. No duplicate values
4. No indexing
5. Fast searching

Real-life Example:
Unique roll numbers in a class.

4. DICTIONARY
-----------------------------------------

Definition:
A dictionary stores data in key-value pairs.

Example:

student = {
    "name": "Sadham",
    "age": 22,
    "city": "Chennai"
}

print(student)

Output:
{'name': 'Sadham', 'age': 22, 'city': 'Chennai'}

Accessing a value:

print(student["name"])

Output:
Sadham

Changing a value:

student["age"] = 23

print(student)

Output:
{'name': 'Sadham', 'age': 23, 'city': 'Chennai'}

Characteristics:
1. Stores key-value pairs
2. Ordered
3. Changeable
4. Keys must be unique
5. Fast access using keys

Real-life Example:
Student record system.

COMPARISON TABLE
----------------

List
-----
Ordered       : Yes
Changeable    : Yes
Duplicates    : Yes
Indexing      : Yes

Tuple
------
Ordered       : Yes
Changeable    : No
Duplicates    : Yes
Indexing      : Yes

Set
----
Ordered       : No
Changeable    : Yes
Duplicates    : No
Indexing      : No

Dictionary
----------
Ordered       : Yes
Changeable    : Yes
Duplicates    : Keys No, Values Yes
Indexing      : By Key

SUMMARY
---------

List       : Ordered + Changeable
Tuple      : Ordered + Unchangeable
Set        : Unique Values Only
Dictionary : Key : Value Pairs
